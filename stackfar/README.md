## Canonical hierarchy

```text
StackOra (SF-ORA)
  └── Domain (Concepts, RAC, Data Guard, ASM, etc.)
      └── Oracle Version (19c | 26ai | other releases when approved)
          └── Official Book Chapter
              └── Section / Objective
                  └── 15 bilingual output classes (FA and EN)
```

Every version keeps the original Oracle Table of Contents and chapter numbers. Shared concepts are connected using cross-version mappings, **not copied into a misleading identical outline**.

# فهرست منابع

[کتابخانهٔ کوئری‌های DBA اوراکل](../README.md)

از لینک‌های منابع برای یافتن نسخه‌های قدیمی، دستورالعمل‌های داخلی، ابزارهای ثالث و منابع SQL Server استفاده کنید.

هنگام عیب‌یابی از راهنمای دسته‌ها شروع کنید. فهرست خصوصی در OneNote فایل‌های آرشیوی و صفحه‌های اصلی را به این موضوعات وصل می‌کند. منابع قدیمی ممکن است به نسخه‌های قدیمی، تنظیمات کلاینت یا اسکیماهای محلی وابسته باشند.

## ابزارهای عیب‌یابی اوراکل Tanel Poder

آرشیو منبع شامل نسخهٔ TPT در کامیت زیر است. برای وابستگی‌های SQL*Plus ساختار اصلی پوشه‌ها را حفظ کنید. این بسته ترکیبی از ابزارهای اندازه‌گیری، آزمایشگاهی و مدیریتی است. قبل از اجرا دامنه و مجوز هر ابزار را بررسی کنید.

- [نسخهٔ ثابت upstream](https://github.com/tanelpoder/tpt-oracle/tree/2de19865e4fb3f8503f720bc18a3e4d7d9539de7)
- [Apache License 2.0](https://github.com/tanelpoder/tpt-oracle/blob/2de19865e4fb3f8503f720bc18a3e4d7d9539de7/LICENSE.txt)

| بخش upstream | کاربرد |
| --- | --- |
| Root scripts | اندازه‌گیری سریع SQL*Plus و یافتن Cursor و آبجکت |
| `ash/`, `awr/` | فعالیت نمونه‌برداری‌شده و بار تاریخی. مجوز Pack را بررسی کنید |
| `exadata/`, `im/`, `ppx/` | ابزارهای پلتفرم، In-Memory و اجرای موازی |
| `statspack/`, `tools/` | گزارش‌گیری و Collectorهای کمکی با پیش‌نیازهای جدا |
| `setup/` and lab folders | راه‌اندازی اختیاری و تمرین برای محیط‌های ایزوله |

## دامنهٔ اجرا

مرجع نسخه‌ها Oracle Database 19c است. ستون ویوها، مجوز و قابلیت‌ها را با نسخه، Edition و کانتینر مقصد تطبیق دهید. SQL به‌صورت ایستا بررسی شده است. پیش از اتکای عملیاتی، خروجی و دسترسی را در محیط تست بسنجید.

از حساب مانیتورینگ دارای دسترسی به ویوها و پکیج‌های ذکرشده استفاده کنید. نمونه و PDB را بررسی کنید و از مسیر `ORACLE/` در SQL*Plus، SQLcl یا حالت اجرای اسکریپت در SQL Developer اجرا کنید. نمونهٔ تنظیم Bind برای گزارش SQLهای اخیر کش‌شده در ادامه آمده است.

```sql
VARIABLE p_minutes NUMBER
EXEC :p_minutes := 30
@sql-plans/top-cached-sql-by-cpu.sql
```

برای متغیرهای Bind به‌جای مقادیر نمونه، شناسه‌ها و نام‌های دقیق نشست تشخیصی خودتان را بگذارید. برای گزارش CLOB در SQL*Plus از `SET LONG 1000000` و `SET LONGCHUNKSIZE 32767` استفاده کنید.

برای ASH و AWR مجوز Oracle Diagnostics Pack را مطابق Edition و سرویس بررسی کنید. در محیط‌هایی که مجوزها جداگانه‌اند، Real-Time SQL Monitoring به Tuning Pack و پیش‌نیاز آن Diagnostics Pack نیاز دارد. Snapshot دستی AWR در مخزن AWR می‌نویسد. سایر اسکریپت‌ها خواندنی و تشخیصی‌اند. [اطلاعات مجوز Oracle](https://docs.oracle.com/en/database/oracle/oracle-database/19/dblic/Licensing-Information.html)

برای پیدا کردن اسکریپت‌های قدیمی و یادداشت‌های خصوصی مرتبط، از فهرست منابع در OneNote استفاده کنید.
